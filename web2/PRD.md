# [PRD] 부산시 업종별 상가(상권) 인터랙티브 지도 웹 서비스 (Busan Commercial Map)

---

## 1. 프로젝트 개요 (Overview)

### 1.1 배경 및 목적
* **데이터 기반의 부산 상권 시각화**: 소상공인시장진흥공단의 최신 공공데이터를 기반으로 **부산광역시 내 총 159,689개 상가 업소**와 **247개 세부 업종 코드**를 직관적인 지도 웹 서비스로 구현합니다.
* **업종별 & 지역별 다차원 탐색**: 사용자가 부산의 16개 구·군 및 행정동별로 어떤 상가들이 밀집해 있는지, 특정 업종(대분류 10종, 중분류 75종, 소분류 247종)이 어디에 분포해 있는지를 손쉽게 필터링하고 검색할 수 있도록 합니다.
* **100% 무료 지도 플랫폼**: 상용 지도 API(카카오, 네이버, 구글 등)의 도메인 등록, 월별 트래픽 쿼터 과금, API 키 발급 등의 제약이 없는 **완전 무료 오픈소스 지도(Leaflet.js + OpenStreetMap / CartoDB)**를 사용합니다.
* **모바일 퍼스트 반응형 경험**: PC는 물론 스마트폰 환경에서도 엄지손가락으로 간편하게 필터링과 조작이 가능한 반응형 바텀시트(Bottom Sheet) 인터페이스를 제공합니다.

### 1.2 핵심 가치 (Core Values)
1. **Zero Cost & Zero Key**: API 키 등록 없이 누구나 로컬이나 웹에서 즉시 구동 가능한 무료 오픈 지도.
2. **High-Performance Large-Scale Visualization**: 약 16만 건의 대용량 데이터를 브라우저 렉(Lag) 없이 매끄럽게 탐색하는 분할 파티셔닝 & 마커 클러스터링(Marker Clustering) 기술.
3. **Hierarchical Industry Classification**: 대분류(10개) → 중분류(75개) → 소분류(247개)로 이어지는 체계적인 업종 필터링 및 카테고리별 시각화.
4. **Seamless Mobile UX**: 모바일 브라우저 최적화 바텀시트, 반응형 사이드바, 내 위치(GPS) 연동 탐색.

## 2. 타겟 사용자 및 주요 활용 시나리오

### 2.1 타겟 사용자
* **예비 창업자 및 소상공인**: 부산 내 특정 동네(예: 전포카페거리, 해운대 구남로)의 경쟁 업종 밀집도 및 공백 상권을 분석하려는 창업 준비자.
* **일반 시민 및 관광객**: 특정 지역의 음식점, 카페, 숙박, 편의시설 등을 위치 기반으로 빠르게 찾고자 하는 사용자.
* **지자체 및 상권 리서처**: 부산시 16개 자치구별 상업 인프라와 산업군 분포를 시각적으로 조사하려는 분석가.

### 2.2 주요 사용자 시나리오
1. **시나리오 A: 모바일 - 내 주변 맛집/카페 탐색**
   * 스마트폰으로 웹페이지에 접속하여 `내 위치 찾기(GPS)`를 터치합니다.
   * 지도가 현재 위치로 이동하고, 상단 업종 칩에서 `음식` > `카페`를 선택합니다.
   * 내 반경 500m 내의 카페 마커들이 표시되며, 하단 바텀시트에 거리순 상가 목록이 나옵니다.
   * 특정 카페를 터치하면 상세 주소와 네이버/카카오 길찾기 링크를 확인합니다.

2. **시나리오 B: 데스크톱 - 구·군별 상권 및 특정 업종 분포 분석**
   * PC 화면에서 지역 필터로 `해운대구`를 선택합니다.
   * 지도가 해운대구 전체로 줌 이동하고, 우측 업종 선택기에서 `소매` 대분류 내 `슈퍼마켓`, `편의점`을 필터링합니다.
   * 클러스터링된 숫자 뱃지를 통해 어느 동(우동, 좌동, 중동 등)에 유통 상가가 밀집해 있는지 한눈에 파악합니다.

## 4. 대용량 데이터 최적화 아키텍처 (Key Technical Challenge)

### 4.1 문제 정의
* 159,689건(원천 82.8MB)을 하나의 JSON으로 브라우저에 한꺼번에 로드하면:
  1. 모바일 기기에서 30MB 이상의 데이터 다운로드로 인한 느린 초기 로딩.
  2. 수십만 개 객체 역직렬화로 인한 모바일 브라우저 탭 다운(Crash) 위험.
  3. 지도 위 과도한 DOM 렌더링으로 렉 발생.

### 4.2 솔루션: 3단계 계층형 경량화 & 온디맨드 로딩 전략
1. **메타데이터 & 요약 통계 분리 (`summary.json` ~30KB)**
   * 16개 구·군별 상가 수, 행정동 목록, 10대 대분류 통계, 75개 중분류/247개 소분류 코드 트리만 포함.
   * 웹 진입 시 즉각 로드되어 지도에 16개 구·군 중심 마커/통계 버블을 즉시 렌더링.
2. **구·군별 데이터 파티셔닝 (`data/districts/{gu_code}.json`)**
   * 16개 구·군별로 데이터 분할 저장 (각 파일당 평균 4,000~20,000건, 압축 시 300KB~1.5MB 수준).
   * 사용자가 특정 구·군을 선택하거나 해당 영역으로 지도를 줌인할 때 비동기(`fetch`)로 필요 데이터만 온디맨드 로딩.
3. **컴팩트 배열 포맷 (Compact Array Schema)**
   * JSON 키 명칭 반복(예: `"name"`, `"addr"`)을 제거하여 크기를 75% 절감:
   * 포맷: `[id, name, branch, subCode, dong, addr, lat, lng]`
   * 예시: `["MA01...", "스타벅스", "해운대점", "I21201", "우동", "해운대해변로 280", 35.158, 129.160]`
4. **마커 가상화 & 클러스터링**
   * `Leaflet.markercluster`의 `chunkedLoading: true` 옵션 활성화로 1만 개 이상의 마커를 백그라운드에서 분할 렌더링.

## 5. 핵심 기능 요구사항 (Functional Requirements)

### 5.1 무료 지도 엔진 및 인터랙션 (FR-1)
* **FR-1.1 (엔진 및 타일)**: Leaflet.js v1.9.4 기반. OpenStreetMap(OSM) 기본 타일과 CartoDB Positron(밝고 모던한 고대비 타일) 레이어 전환 스위처 제공.
* **FR-1.2 (초기 뷰)**: 부산시청 중심 좌표(`35.1795543, 129.0756416`), 줌 레벨 11로 부산 전역 표시.
* **FR-1.3 (고성능 클러스터링)**: 지도 줌 레벨에 따라 인접 상가를 동적 원형 클러스터로 그룹화. 클러스터 클릭 시 해당 영역으로 자동 줌인(Spiderfy 효과 지원).
* **FR-1.4 (지도 제어 컨트롤)**:
  * 줌 인/아웃 (`+` / `-`)
  * 부산 전체 보기 (화면 초기화 리셋 버튼)
  * 내 위치(GPS Geolocation) 실시간 마커 및 반경 표시 버튼

### 5.2 업종코드 다단계 필터링 (FR-2)
* **FR-2.1 (대분류 탭/칩 바)**:
  * 상단에 10대 대분류(음식, 소매, 수리·개인, 과학·기술, 교육, 숙박 등) 칩 바 제공.
  * 대분류 선택 시 고유 테마 색상 활성화 및 해당 카테고리 마커만 즉각 필터링.
* **FR-2.2 (중분류 / 소분류 필터)**:
  * 대분류 선택 시 연관 중분류(75종) 및 소분류(247종) 드롭다운 연동(Cascading Dropdown).
  * 예: `음식` 선택 시 → `중분류: 커피·음료`, `소분류: 카페` 선택 가능.
* **FR-2.3 (업종 키워드 빠른 검색)**:
  * 업종 검색창에 "치킨", "편의점", "약국", "미용실" 입력 시 자동완성 및 즉각 필터링.

### 5.3 지역별 탐색 및 상호/주소 검색 (FR-3)
* **FR-3.1 (지역 다단계 선택)**:
  * 부산 16개 자치 구·군 드롭다운 (`전체`, `해운대구`, `부산진구`, `수영구` 등).
  * 구·군 선택 시 지도가 해당 구 중심으로 부드럽게 이동(FlyTo 애니메이션)하며, 해당 구의 행정동 드롭다운 목록 자동 채움.
  * 행정동 선택 시 해당 동 영역으로 정밀 이동.
* **FR-3.2 (통합 텍스트 검색)**:
  * 상호명, 지점명, 도로명/지번 주소 대상 통합 검색.
  * 입력 시 디바운스(Debounce 300ms) 적용으로 부드러운 실시간 검색 결과 제공.
* **FR-3.3 (필터 초기화)**:
  * 모든 지역/업종/검색어를 기본값으로 즉시 리셋하는 원클릭 초기화 버튼.

### 5.4 상가 목록 및 상세 정보 (FR-4)
* **FR-4.1 (동적 상가 목록 카드)**:
  * 현재 지도 화면(또는 필터 결과)에 해당하는 상가들을 카드 형태로 리스트업.
  * 카드 내용: 업종 뱃지(색상), 상호명, 지점명, 도로명주소, 현재 뷰포트 중심과의 거리.
* **FR-4.2 (상세 정보 팝업 / 바텀시트)**:
  * 지도 마커 클릭 또는 목록 카드 클릭 시 상세 정보 팝업(PC) 또는 바텀시트 확장(모바일):
    * 업종 분류: `대분류 > 중분류 > 소분류` 풀 네임
    * 상호명 및 지점명
    * 도로명주소 및 지번주소, 우편번호
    * 지도상 좌표 및 주소 복사 버튼
    * **길찾기 연동 버튼**: 네이버 지도, 카카오맵 바로가기 외부 링크 제공

## 6. 모바일 반응형 UI/UX 설계 (Non-Functional Requirements)

### 6.1 모바일 퍼스트 인터페이스 (Mobile-First UX)
* **반응형 바텀시트 (Bottom Sheet UI)**:
  * 모바일 화면(폭 < 768px)에서는 지도를 풀스크린으로 배치하고 화면 하단에 3단 조절 바텀시트 배치:
    1. **접힘 (Peek)**: 핸들바 + 검색창 요약 + "검색된 상가 N개" 헤더만 노출.
    2. **중간 (Half)**: 화면의 45% 높이로 상가 목록 스크롤 가능.
    3. **펼침 (Full)**: 화면의 90% 높이로 전체 필터(지역/업종 상세) 및 목록 탐색.
  * 터치 스와이프 제스처 지원(위/아래 드래그로 시트 높이 조절).
* **한 손 조작 최적화**:
  * 주요 필터 칩(업종 가로 스크롤 칩)과 내 위치 버튼을 엄지손가락이 닿기 쉬운 하단 및 측면에 배치.

### 6.2 데스크톱 인터페이스 (Desktop 2-Pane Layout)
* **좌측 사이드바 (폭 380px)**:
  * 상단: 통합 검색창 및 지역(구/동) 선택기
  * 중단: 업종 대분류 칩 및 세부 업종 선택기
  * 하단: 검색 결과 상가 목록 (무한/가상 스크롤 지원)
* **우측 풀스크린 지도**:
  * 클러스터링 마커, 줌/원점 리셋 컨트롤, 우측 상단 타일 레이어 전환 토글.
